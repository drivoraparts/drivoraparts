## Pricing

Kit target = sum of the component target prices. Each component is priced 3-5% (target 5%) under the lowest verified US retailer for that exact part number, so each kit lands 3-5% under the summed benchmark. No extra kit discount, sale price or reference price is applied. No supplier cost is on file, so every kit total is a competitive target flagged for profitability review, not a selling price. No competitor price for an identical kit was researched: the benchmark adds the cheapest individual listings, which may come from different sellers.

## Before any kit can be published

1. Supplier cost for every component (and kitting/packaging cost), plus a minimum margin.
2. A licensed photo of each kit's actual contents.
3. Owner approval of each kit price.
4. Storefront support for bundle listings: the current catalog has single-product listings only, so a kit would need either one listing with its own SKU and stock reserved across components, or an add-all-to-cart bundle. That is a code change not made here.
